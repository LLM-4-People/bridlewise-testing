# Public icons

The application icons referenced by the PWA manifest.

## What each file does

Every file here is generated by `scripts/generate-pwa-icons.mjs` from the
one mark geometry (`src/cockpit/shell/brand-mark.ts`) in the token owner's
Carbon colours (`src/cockpit/tokens.css`); never edit them by hand.
`tests/prevention/pwa.test.ts` refuses a drifted file.

- `icon.svg` — the vector brand mark (the rein, three record lines and the
  live beam) on its rounded Carbon tile.
- `icon-192.png` — the 192×192 raster icon (full-bleed tile).
- `icon-512.png` — the 512×512 raster icon, also declared as the maskable
  icon in the manifest (the mark sits inside the safe zone).

## Where it lives and what consumes it

The folder lives at `public/icons/`. `public/manifest.json` and
`index.html` reference the icons by URL; no module imports them.
