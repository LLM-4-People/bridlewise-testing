# Bugs and issues

This is the public issue index for the development floor. The full private
workflow tracker is not published.

Use the repository issue tracker for a reproducible public bug. A useful report
names the exact command, the expected behavior, the observed behavior, and
whether the failure reproduces from a fresh clone. Do not include credentials,
private paths, the raw corpus, or personal data.

The current work lanes are on the [task board](TASKS.md). The milestone exit
criteria are on the [roadmap](https://llm-4-people.github.io/bridlewise-testing/floor/roadmap/).
