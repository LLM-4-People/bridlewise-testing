# Public floor tasks

This is the public task board for the Bridlewise development floor. It is a working list, not a release schedule. Each row names one outcome; the detailed exit criteria live in the [build roadmap](../floor/roadmap.md).

Each row is one item file in `docs/trackers/items/` (format `bridlewise-tracker-item/v1`, read by `engine/src/workflow/failure-owners.ts`). The board below is generated from those files by `harness sync`: a row changes only by editing its item, and `harness check` refuses a board that differs from its items.

**Flaky burn-down owners.** Each row owns at least one entry in the tracked flaky burn-down list. The owner is the task that must reproduce, fix, or explicitly retire the entry; a row re-owns an entry only by the commit that adds it (`engine/src/workflow/flaky-burn-down.ts` `entryAddedWithOwner`).

**Private web lanes.** The public snapshot does not publish the private web run history, so these lanes own no entry here. They remain the private floor's workstreams — ordinary work, not a claim that a private failure still exists.
