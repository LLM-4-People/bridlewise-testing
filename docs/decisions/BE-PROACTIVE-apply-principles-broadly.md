# Be proactive: apply principles broadly

A rule is usually stated on one example, but the problem it names rarely
lives in one place. So a rule or a finding is applied to everything it
plausibly covers, not only to the case that prompted it.

The user, 2026-09-27: "be proactive and apply anything else related to this
not mentioned here. apply principles broadly".

- A rule or finding covers everything it plausibly applies to, not only the
  case it was stated on.
- It works with [UR-19](UR-19-every-rule-is-retroactive.md) (every rule
  applies to all existing code) and
  [UR-18](UR-18-every-issue-class-gets-a-mechanical-guard.md) (the class, not
  the instance, gets the guard).

How it is enforced: by review. It is a working rule with no mechanical guard
of its own; the breadth it asks for is enforced where a guard's scope is
checked ([UR-20](UR-20-tests-are-always-broad.md)).
