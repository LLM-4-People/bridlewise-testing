# People can collaborate, help and interact

Bridlewise is built mostly by agents, but it is meant to be a project people
can join. So a person's contribution goes through the same checks as an
agent's, getting started is easy, and the agents' work is written so a person
can read it and answer it.

The user, 2026-10-21: "about github, we also want people to be able to
collaborate, help and interact".

- Safe contributions from forks, through the same door as agents.
- Onboarding: a one-click development container, generated guides, and good
  first issues drawn from the tracker.
- Discussions and public RFCs for decisions; triage bots; contributor credit;
  governance and moderation.
- Agent pull requests are legible and answerable by humans.

Done so far: the contribution guide, governance and code of conduct
(`CONTRIBUTING.md`, `GOVERNANCE.md`, `CODE_OF_CONDUCT.md`), issue and pull
request templates, and a development container (`.devcontainer/devcontainer.json`).

Still missing: the files are written by hand, not generated; there are no
triage or IssueOps bots, no good-first-issue projection from the tracker, no
contributor credit, and fork pull requests do not yet go through the agents'
door (P5.4).
