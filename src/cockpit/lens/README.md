# Lens

The lens surface: the provenance instrument's callout — what a value is and where it came from, on hover.

## What each file does

- `lens-callout-data.ts` — LENS callout model — pure functions.
- `LensCallout.svelte` — THE LENS CALLOUT — ⌘L then hover: a surface's provenance.

## Where it lives

The folder lives at `src/cockpit/lens/`.
