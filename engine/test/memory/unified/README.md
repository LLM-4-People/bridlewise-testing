# unified

The `engine/test/memory/unified/` folder of the development surface.

## What each file does

- `probe-infrastructure.test.ts` — probe infrastructure regression tests (counts, fact-marker uniqueness, coverage).
- `unified-context-manager-adversarial.test.ts` — aDVERSARIAL tests for the unified context manager's trim mechanism.
- `unified-context-manager.test.ts` — behavioral tests for the unified context manager's tool_calls grouping.
- `unified.test.ts` — the `unified.test` module.

## Where it lives and what consumes it

The folder lives at `engine/test/memory/unified/`.
