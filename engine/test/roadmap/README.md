# roadmap

The `engine/test/roadmap/` folder of the development surface.

## What each file does

- `forecast.test.ts` — the milestone forecast: the same inputs give the same seeded Monte-Carlo band and another seed another sample; a constant pace forecasts exactly across a 53-week year's end; more remaining never forecasts sooner; nothing remaining is complete; each guard (too little history, too few closed, too few trials within the horizon) answers `unknown` with its plain reason and a band exactly at its edge; malformed inputs refused typed; ISO-8601 weeks across year boundaries, the 53-week years checked against an independent rule, and calendar days that do not exist refused.
- `graph.test.ts` — the roadmap's dependency graph (`scripts/roadmap/graph.ts`): edges and their typed refusals (an unknown id, a repeated id or edge, a cycle named in order), the per-milestone critical path (open nodes only, across milestones, a finished node breaking a chain, weights, id-order ties), the deterministic layered layout (edge direction, no overlap, one mid-point per crossed layer, barycenter sweeps), the accessible SVG (every text escaped, critical and blocked classes, no colour or inline style) and the page script (compiles, under its size cap, safe on a page without the graph, upstream/downstream marking, the milestone filter and Escape on a minimal DOM).
- `history.test.ts` — the roadmap through git history, replayed on a scratch repository at fixed commit times: one snapshot per first-parent commit that changed an item (none for an unrelated commit or a side branch's own commit; a merged branch seen at its merge), an older schema recorded unparseable and never guessed; every change named in order; `Item:` trailers on every commit with the pull request the subject names, near-misses ignored and a malformed value refused; the burn-up, the weekly closed-as-completed transitions and `snapshotAt` by commit and by date; and the compact document's fold equal to the snapshot at every commit, through JSON.
- `model.test.ts` — the roadmap model (`scripts/roadmap/model.ts`): a closed item is done only while its bound checks passed on the rendered commit, otherwise retracted under Now; a missing checks snapshot reads unknown and retracts nothing; in flight, blocked and ready; Next and Later with their reasons; milestone progress and state; areas, gaps, risks and the why; purity.
- `render.test.ts` — the renderers (`scripts/roadmap/render.ts`): escaping through the one markup owner, the retraction and the live gap stated, record links pinned to the commit, forecasts as a band or an honest unknown, the burn-up, the README block, the print page, the Atom feed and the JSON, and byte-identical re-renders.
