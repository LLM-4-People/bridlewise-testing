# Traceability artifacts

Small generated manifests the verification gates consume.

## What each file does

- `artifacts/manifest.json` — the traceability artifacts manifest: the
  inventory of the generated artifacts in this tree, with their roles and
  digests.

## Where it lives and what consumes it

The folder lives at `engine/traceability/artifacts/`. The slice-projection
and candidate verifiers read the manifest; it is regenerated by the harness
commands, not hand-edited.
