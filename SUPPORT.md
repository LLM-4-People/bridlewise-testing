# Support

The Bridlewise development floor is a **developer preview**. There is no commercial support, no SLA, and no guarantee that a question will be answered.

## Where to ask

- **Questions and design discussion:** GitHub Discussions on the product repository.
- **Reproducible bugs in the product:** [bridlewise issues](https://github.com/LLM-4-People/bridlewise/issues).
- **Test-floor or verification issues:** issues in this repository.
- **Security reports:** follow [SECURITY.md](SECURITY.md). Do not open a public issue with exploit details.

## Before opening an issue

1. Confirm the revision (commit SHA) and branch.
2. Read [docs/testing.md](docs/testing.md) and [docs/cli.md](docs/cli.md).
3. Search existing issues and discussions.
4. Reduce the report to one reproducible behavior.
5. Include OS, kernel, Node version, npm version, and the exact commands.
6. Remove secrets, absolute home paths, private repository names, and personal data from logs.

## Out of scope

- Production deployment support.
- Security guarantees for sensitive codebases.
- Provider account, billing, or outage issues.
- Making the preview production-ready on a deadline.
- Support for non-Linux hosts beyond the documented WSL caveats.
